# Como contribuir

Obrigado por considerar contribuir!

1. Consulte [ROADMAP.md](ROADMAP.md) e as [Issues](../../issues).
2. Abra ou comente uma Issue para propor funcionalidades e correções.
3. Para contribuições de código, descreva escopo, testes e possíveis impactos no banco.
4. Prefira pull requests pequenos, com explicação e testes quando aplicável.
5. Não inclua bancos com dados proprietários, imagens, marcas, elencos licenciados ou material protegido sem autorização apropriada.

**Licença:** ainda não definida. Até que seja incluído um arquivo LICENSE, o repositório público não concede automaticamente permissão geral para redistribuição ou reutilização de código.
